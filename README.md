# ReThink LG Home Assistant app

This app repository builds a pinned commit from the [RH90V9 fixes branch](https://github.com/emilagervigstarup/rethink/tree/rh90v9-fixes).
It provides local Power off, Warm Air duration and cycle controls for the LG RH90V9_WW dryer.
The app packaging is based on [jmcjm/rethink-ha-addon](https://github.com/jmcjm/rethink-ha-addon).

Add `https://github.com/emilagervigstarup/rethink#ha-app` in the Home Assistant app store
and install **ReThink Cloud – LG Dryer**. See the app's Documentation tab before migrating
an existing installation.
